Llenya Burger House - projecte web de demostració

Estructura:
  index.html      Estructura de la pàgina (capçalera, menú, contenidor principal)
  css/style.css   Estils (mòbil primer, adaptat a PC, mode fosc)
  js/data.js      Categories, plats i ofertes
  js/app.js       Navegació per hash, vistes, carrusel automàtic, menú i reserva

Ús: obre index.html al navegador. No cal servidor ni base de dades.
Les tipografies es carreguen de Google Fonts (cal connexió; si no, es veuen les alternatives).
